## Importante sobre a tele-busca

A Pet da Pri **não dá banho na casa do cliente**. A tele-busca funciona assim: ela busca o pet, faz o banho/tosa no espaço dela, e devolve depois. Isso já está deixado bem claro no site (página de Serviços e no formulário de Agendamento), pra evitar mal-entendido do cliente.

## Como usar isso na conversa com ela

1. Publique este site em um repositório GitHub separado (veja o passo a passo de GitHub Pages que já usamos antes) ou rode localmente e mostre a tela pra ela.
2. Deixe claro que é um protótipo/demonstração - os preços e horários são só ilustrativos.
3. Se ela topar, os próximos passos seriam: confirmar horário real, preços reais, e pegar fotos de verdade (do espaço, dela trabalhando, de pets atendidos) para substituir os banners de exemplo.
